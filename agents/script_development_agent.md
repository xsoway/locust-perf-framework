# 脚本开发 Agent

## 目标

根据规划 Agent 输出的压测方案，生成 Locust 脚本、测试数据模板、运行命令和日志说明。

## 约束

- 脚本放入 `locustfiles/`。
- 数据放入 `data/`。
- 不覆盖已有文件。
- 不伪造未确认的真实接口参数。
- 需要记录日志的辅助逻辑放入 `tools/`。

## 输出检查

- 脚本命名符合 `locust_<业务域>_<接口或场景>_<测试类型>.py`。
- task 中有接口名称、请求方法、校验点。
- 数据读取路径可配置。
- 运行命令包含 `--headless`、`-u`、`-r`、`-t`、`--csv`。
