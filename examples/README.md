# examples/ — 可公开的压测示例

本目录存放**可直接复现、可公开参考**的压测示例，帮助开发者和使用者快速上手
`locust-perf-framework` 的标准流程与产物形态。

每一个示例都是**端到端跑通**的结果：脚本 → 数据 → 预检 → 压测 → 原始产物 →
中文 HTML 报告的全部产物都放在该示例的子目录内，并附 `README.md` 给出从零复现
的步骤命令。

## 示例清单

| 示例 | 场景 | 说明 |
| --- | --- | --- |
| [`health-check-demo/`](./health-check-demo/) | 健康检查接口 | 单步基准 + 阶梯加压找拐点，产出完整中文报告 |
| [`pressure-test-demo/`](./pressure-test-demo/) | 健康检查接口（压力测试） | 加压到服务过载，演示击穿点判定与熔断，产出"需修复"诊断报告 |

---

## 约定与安全

- 所有示例均为**脱敏演示数据**，被测对象使用本地 Mock 或 `example.*` 占位，
  不包含任何真实业务域名、账号、密钥。
- `reports/`、`logs/` 下的真实运行产物默认不入库（见 `.gitignore`）；
  本 `examples/` 目录存放的是精选教学产物，有固定的「数据 + 原始 CSV + 报告」
  精简形态，供对照学习。
- 新增示例请遵循：每个示例一个子目录，`README.md` 必须给出可一次性复现的命令，
  产物需脱敏且可公开。
